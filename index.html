HTTrack

A free, open-source offline website copier

What is HTTrack?

HTTrack is a free, open-source offline browser utility that lets you download an entire website from the Internet to a local directory. It recursively builds all directories, fetching HTML pages, images, and other files so you can browse the site offline exactly as it appears online.

Key Features

  • Offline browsing — Download a full website for local access.
  • Recursive downloading — Follows links and rebuilds the directory structure locally.
  • Resume support — Resume interrupted downloads and update existing mirrors.
  • Filter rules — Include or exclude files by type, size, domain, or path.
  • Multi-platform — Runs on Windows, Linux, macOS, and other Unix systems.
  • Open source — Released under the GNU General Public License (GPL).

How It Works

  1. HTTrack connects to the specified URL.
  2. It parses each HTML page for links to other resources.
  3. All linked pages, images, CSS, JS, and other assets are downloaded.
  4. Internal links are rewritten to point to the local copies.
  5. The result is a fully navigable, self-contained copy on your disk.

Basic Usage

# Install on Debian/Ubuntu
sudo apt-get install httrack

# Mirror a website
httrack "https://example.com" -O "/path/to/output"

# Mirror with a depth limit (3 levels)
httrack "https://example.com" -O "/path/to/output" -r3
